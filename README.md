# 🎬 超8 · 去水印下载

🌐 **https://s8.v8i8.com**

---

## 功能特色

- ✅ **9 大平台支援** — YouTube、抖音、TikTok、小紅書、蝦皮、Bilibili、Instagram、Twitter/X、Facebook
- ✅ **零伺服器流量** — 只解析回传 CDN 直链，用户端直接下载
- ✅ **三國語言** — 繁中 / 簡中 / English

---

## 使用方式

1. 複製影片連結
2. 貼上到超8輸入框
3. 按「解析」→ 取得 CDN 直鏈
4. 按「下載」→ 從 CDN 直接下載
